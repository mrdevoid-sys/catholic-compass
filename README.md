# Catholic Compass

Catholic Compass is a Catholic pilgrimage and travel-planning app. The current Expo project is being prepared for iOS builds through Expo Application Services and Apple Store Connect.

## Expo setup

The Expo project in Expo is connected to this repository. If the mobile app lives in a subdirectory, set the Expo GitHub base directory to that folder.

Current intended mobile app directory:

```text
apps/mobile
```

## Important data policy

Do not fabricate Catholic site data, Mass schedules, relic claims, venue coordinates, or driving routes. Imported listings must remain clearly distinguished from independently source-checked information.
